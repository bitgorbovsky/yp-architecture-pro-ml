# Описание
В качестве исходных текстов были взяты англоязычные тексты по вселенной Star Wars. Тексты выгружаются из Wookiepeddia, затем переводятся в полностью неизвестный мир, с генерируемыми названиями планет, рас, организаций, а также с заменёнными названиями различных политических и социальных институтов. Это сделано с целью полностью превратить мир "Звёздных войн" в мир, который не будет известен нейросети.

В качестве генератора слов используется алгоритм генерации назвваний планет, взятый из игры Elite.
Для сохранения логически связанной структуры текста и смысловых связей, решено было провести более гранулярные замены по отдельным словам и именам собственным. Например, Luke Sywalker и Anakin Skywalker в новом мире будут иметь разные имена, но одну и ту же фамилию, тем самым мы сохраняем логику мира.
# Структура
* `data/replacements.json` - словарь гранулярных замен.
* `starwars_entites.json` - словарь с указанием слов, относящихся к миру Star Wars, с указанием замен неспецифических слов на другие (например, fighter -> destroyer), а также с указанием стоп-слов, на которые не нужно генерировать замену.
* `data/raw` - папка с исходниками статьей с WookiePedia.
* `data/knowledge_base` - база знаний.
* `data/extracted` - папка с текстовыми файлами, где каждый файл содержит статью, изввлечённую из страницы html.
* `data/db` - содержит файлы Fiass (векторный индекс) и SQLite3 (хранилище текстовых кусочков и метаданных к ним).
# Заполнение
1. Сперва выполняем команду `python code/grap_pages.py`. Данный скрипт выгружает из сайта определённый набор страниц и сохраняет их в `data/raw`. Это нужно, чтобы доотлаживать логику извлечения чистого текста из страниц без повторной загрузки страниц.
2. Затем выполняем команду `python code/extract_articles.py`. Данный скрипт проверяет содержимое папки `data/raw`, изввлекает из каждой html-страницы чистый текст и сохраняет его в папку `data/extracted` с соответствующим именем.
3. Далее следует сгенерировать файл с заменами. Для этого нужно запустить команду `python code/replacements.py | jq . > data/replacements.json`. Но можно и не запускать, в репозитории уже лежит готовый файл с заменами.
4. После чего выполняем преобразование мира: `python code/transform_articles.py`. После чего в папке `data/knowledge_base` появятся текстовые файлы, которые и являются базой знаний.
