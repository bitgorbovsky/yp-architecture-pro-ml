# Автоматизированное тестирование

## Методика оценки ответов

Поскольку большинство метрик сравнения текста не учитывают его смысл, который может быть передан совершенно другими словами, оценивать ответы будем с помощью самой же БЯМ.

## Запуск испытателя

```bash
python -m rag.verify <API-KEY> <FOLDER> 1&> data/test-log.jsonl
```

## Анализ журналов испытаний

```python
import json

log = open('data/test-log.jsonl', 'rt')
lines = []
while True:
    line = log.readline()
    if not line:
        break
    lines.append(json.loads(line))
```

answers = {}

# Выводы
1. Необходимо определить влияние размера фрагментов документов и их перехлёста на полноту и точность ответов модели. Сейчас документы разбиваются на фрагменты размером в 128 смысловых единиц, с перехлёстом в 32 смысловые единицы, что приводит к слишком коротким фрагментам, что может быть недостаточно для модели.
2. Необходимо определить влияние размерности векторов embedddings на полноту и точность ответов модели. Сейчас размерность векторов - 384 признака.
3. Для экспериментов с генерированными мирами на основе мира Звёздных Войн необходимо улучшать алгоритмы обработки текста и замен слов.
4. Рассмотреть варианты уточнения инструкций для БЯМ.
